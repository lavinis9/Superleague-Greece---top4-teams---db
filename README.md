<h3>ΠΑΡΑΚΑΤΩ ΚΑΙ ΣΤΑ ΑΓΓΛΙΚΑ</h3>
<hr>
<p>This side project is about a complete Database System that we developed as a team, consisting of myself and the members listed at the end of the README. For its implementation, we used <big>real-world data</big> collected from the Transfermarkt website, as this project focuses on the Top 4 teams of the Greek Football League (Super League).</p>

<p>MAIN TOPIC:
Recording the performance of the four major Greek football teams (Olympiacos, Panathinaikos, AEK Athens, PAOK). Data about players, matches, goals, and other statistics will be stored, allowing us to compare their performance and effectiveness.</p>
<br>
<ol>STEPS THAT LED US TO THE FINAL SOLUTION:
<li>Requirements Gathering and Analysis</li>
<li>Database Design
(ER Diagram)</li>
<li>Logical Design</li>
<li>Database Implementation
using SQL</li>
<li>Database Queries and Data Accuracy Verification</li>
<li>Security Policy</li>
</ol>
<br>
<p>What can you find in the repository?--->In the PDF'S folder, you will find the theoretical background and explanation behind each step, except for the ER-DIAGRAM, which is available separately as an image file named ER-DIAGRAM. However, in the SQL CODES folder, all SQL scripts are available, including the tables, relationships, attributes, keys, and the data stored in the model through INSERT statements. Finally, in the .gitattributes file, you will find an entry such as *.sql linguist-detectable=true, which essentially tells GitHub that the repository contains SQL code.</p>
